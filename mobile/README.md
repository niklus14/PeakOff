# PeakOff mobile demo

Static JavaScript prototype for PeakOff customers.

Run `npm run dev`, then open `http://localhost:3001`.

Demo flow:

1. Choose route, transport, and departure time.
2. View ranked offers near the route.
3. Filter offers and open an offer.
4. Claim a demo QR voucher.
5. View claimed vouchers in Offers.

All data is mock data stored locally in the browser.
