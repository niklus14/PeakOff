# PeakOff Business demo

A dependency-free presentation prototype matching the supplied business dashboard references.

Run `npm run dev` here and visit http://localhost:3000. Run `npm run check` for JavaScript syntax validation.

Start with “Walk through demo” for the Azerbaijani speaker narrative. Then open Offers, set pricing limits and apply the recommendation. Preview the customer journey, claim a demo coupon and simulate staff verification. The overview updates sales, visits, claims, redemptions and table availability. Tables can be updated to demonstrate automatically pausing offers when full. Inventory supports toggling limited-stock and welcome offers.

Data stays in this browser through localStorage. “Reset demo” restores the initial scenario. Reporting periods use illustrative data. Pricing is an explicitly simplified demo heuristic, not a trained demand model. Fee: 7% of redeemed sale; minimum profit is checked after fee and product cost. Coupon is an explicitly labeled demo code, not a real QR. Product imagery and fonts require internet access, with system font fallbacks.
